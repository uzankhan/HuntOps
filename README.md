# 🎯 HUNTOPS - Phone Recovery & Tracking System

**Made by Uzan Khan**

## 📖 About
HuntOps is an advanced phone recovery and tracking system that allows you to:
- Track any device using IMEI number
- Remote lock/unlock devices
- Capture photos/audio remotely
- Get real-time location updates
- Report stolen devices to community

## 🚀 Features
- ✅ IMEI-based tracking
- ✅ Real-time GPS location
- ✅ Remote commands (Lock, Camera, Mic, Alarm, Wipe)
- ✅ Location history
- ✅ Community stolen device database
- ✅ Recovery package generation
- ✅ Police report generation

## 🛠️ Tech Stack
- **Backend:** Node.js, Express, TypeScript, PostgreSQL, Socket.io
- **Mobile:** React Native (Android + iOS)
- **Web:** React.js, Leaflet (maps), TypeScript
